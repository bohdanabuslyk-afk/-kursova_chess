# Скріншоти за версіями

Кожна папка – одна версія. Знімки зроблено автоматично (`tools/shots_0*.mjs`) у Microsoft Edge.

## 01 – v0.1: ядро і текстовий ввід
| Файл | Підпис |
|---|---|
| 01 | Початкова позиція |
| 02 | Ходи, введені текстом (помітна вада: порожня горизонталь «сплющена») |
| 03 | Повідомлення про нелегальний хід |

## 02 – v0.2: ходи мишкою
**Покращено:** рівні клітинки, координати, хід мишкою.
| Файл | Підпис |
|---|---|
| 01 | Підсвітка дозволених ходів і взяття |
| 02 | Перетягування фігури |
| 03 | Вибір фігури при перетворенні пішака |
| 04 | Перевернута дошка, шах |

## 03 – v0.3: рушій, складність, колір
**Покращено:** з'явився суперник.
| Файл | Підпис |
|---|---|
| 01 | Вибір кольору та складності |
| 02 | Гра білими проти «Експерта» |
| 03 | Гра чорними: перший хід за комп'ютером |

## 04 – v0.4: запис ходів

| Файл | Підпис |
|---|---|
| 01 | Вікно нової партії |

## 05 – v0.5: аналіз ходів

| Файл | Підпис |

| 04 | Вибір мовної моделі суперником |
| 05 | Нелегальний хід відхилено, друга спроба прийнята |

| 07 | Пояснення ходу |

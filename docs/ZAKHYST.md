# Підготовка до захисту

## Сценарій показу (5–7 хвилин)
1. `python run.py`, відкрити <http://127.0.0.1:8000>.
2. «Нова партія»: показати суперника, колір, 5 рівнів. Почати чорними – перший хід робить комп'ютер.
3. Хід перетягуванням, потім двома кліками, потім текстом (`Nf6`, `Кf6`). Спробувати недозволений хід.
4. «Підказка», «Скасувати», стрілки ← → для перегляду.
5. «Архів» → імпорт PGN (текст «Вічнозеленої партії» нижче) → «Проаналізувати партію».
6. Клацнути ключовий момент: стрілка «як краще», факти, графік.
7. Якщо модель підключено: партія проти LLM, пояснення ходу, питання тренеру.
8. «Оформлення»: темна тема, інша дошка.

Запасний варіант, якщо щось не запуститься: папка `screenshots/`.


## Імовірні запитання
**Навіщо рушій, якщо є мовна модель?** Модель передбачає текст, а не рахує варіанти: може порушити правила
чи не помітити мат. Рушій дає точність, модель – пояснення й «характер».

**Як гарантовано, що модель не зробить нелегальний хід?** Її відповідь – лише текст. Хід перевіряється за
списком дозволених; інакше до трьох спроб, далі ходить рушій (`llm_move` у `app/llm.py`, тести `tests/test_llm.py`).

**Що таке мінімакс і альфа-бета?** Перебираємо ходи, вважаючи, що кожен грає найкраще. Альфа-бета пропускає
гілки, які вже не змінять вибір; результат той самий, перебір менший.

**Навіщо пошук спокою?** Щоб не зупинитися посеред розміну: «взяв ферзя» може бути пасткою.

**Що таке таблиця транспозицій?** Пам'ять оцінених позицій: до тієї самої позиції ведуть різні порядки ходів.

**Як рахується точність?** Через втрату шансів на перемогу, а не пішаків (формули – у матеріалах).

**Чому аналіз обмежено позиціями, а не часом?** Щоб результат був однаковий на будь-якому комп'ютері.
Спершу було за часом, і один хід отримав різні класи – це видно на скріншотах 05/04–06 і 07/00.

**Чому рушій вважає 17.Nf6+ помилкою, а білі виграли?** Він рахує кілька півходів і не бачить кінця
довгої комбінації. Це відоме обмеження; у розвитку – Stockfish.

**Як перевірено, що рівні справді різні?** Турніром: 64 партії, кожен рівень переміг попередній (16:0, 16:0,
16:0 і 13,5:2,5). Таблиця – у матеріалах.

**Де зберігається ключ?** Лише у `.env` на сервері; файл не в git, у браузер не передається.

**Чи працює без інтернету?** Так. З локальною Ollama – навіть мовна модель.

**Чому не React?** Одна сторінка; без збірки проєкт легше запустити й пояснити.

**Що взято готове?** python-chess (правила, зображення фігур), Starlette, uvicorn, SDK openai. Рушій, аналіз,
модуль LLM та інтерфейс написані для цього проєкту.

**Яка роль ШІ у створенні?** Відповідайте чесно: проєкт розроблено з Claude Code; ваша роль – постановка
задачі, вимоги, перевірка, розуміння рішень.

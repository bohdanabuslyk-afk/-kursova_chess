# План розроблення

**Тема:** «Розроблення шахової гри з використанням великих мовних моделей»

## 1. Мета і задачі
Створити вебзастосунок для гри в шахи, у якому класичний пошуковий алгоритм відповідає за
правильність і силу гри, а велика мовна модель (LLM) – за «людську» частину: гру як суперник,
пояснення ходів природною мовою та діалог із тренером.

Задачі:
1. проаналізувати можливості й обмеження LLM у шахах (нелегальні ходи, втрата позиції);
2. спроєктувати архітектуру, де відповідь LLM завжди перевіряється правилами;
3. реалізувати гру, суперника, запис та аналіз ходів;
4. протестувати й оцінити результат.

## 3. Стек
| Частина | Вибір | Чому |
|---|---|---|
| Правила | python-chess | перевірена бібліотека, немає сенсу писати генератор ходів заново |
| Рушій | власний, Python | видно алгоритм (мінімакс, альфа-бета) – є що захищати |
| Сервер | Starlette + uvicorn | легкий асинхронний HTTP-сервер |
| LLM | SDK `openai` зі змінною адресою | той самий код для OpenAI, Ollama, Groq та ін. |
| Клієнт | HTML + CSS + JavaScript без фреймворків | запускається без збірки |
| Тести | unittest | стандартна бібліотека |
